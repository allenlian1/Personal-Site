LeafPilot

  • GitHub

LeafPilot is an AI-powered LaTeX editor that won second best use of Groq at Hack the North 2025. It addresses the lack of intelligent assistance in existing typesetting platforms. The system generates and compiles LaTeX documents directly in the browser while seamlessly embedding Manim animations for mathematical visualizations. Users can upload various resources including text notes and audio recordings, which the platform processes and structures into polished PDF documents. Built with Next.js and FastAPI, LeafPilot uses Groq as the inference engine for LaTeX generation and file processing, with Gemini handling agent reasoning and tool calls. The platform manages asynchronous workflows that combine AI generation, LaTeX compilation, and Manim rendering without requiring local setup. This approach enables students and researchers to focus on content creation rather than formatting complications.
